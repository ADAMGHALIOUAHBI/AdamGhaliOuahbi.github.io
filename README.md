## 🏗️ WEBSITE ARCHITECTURE & LAYOUT

Build a complete, real website with a structured interface, not just a static landing page.

The entire application must follow this layout:

```text
┌─────────────────────────────────────────────────────┐
│                  FIXED TOP HEADER                    │
│                                                     │
│  [LEFT MENU]       GHALI'S WORLD       [RIGHT MENU]  │
├─────────────────────────────────────────────────────┤
│                                                     │
│                                                     │
│              CENTERED MAIN CONTAINER               │
│                                                     │
│        ┌─────────────────────────────────┐          │
│        │                                 │          │
│        │         MAIN CONTENT            │          │
│        │                                 │          │
│        │     Games • Discover • Create   │          │
│        │                                 │          │
│        │       Responsive Sections       │          │
│        │                                 │          │
│        └─────────────────────────────────┘          │
│                                                     │
│                                                     │
├─────────────────────────────────────────────────────┤
│                  FIXED BOTTOM FOOTER                │
│          © Ghali's World • Made with 💙              │
└─────────────────────────────────────────────────────┘
```

### 1. 🔝 Fixed Header

Create a fixed header positioned at the top of the viewport.

Requirements:

- Always visible during page scrolling.
- Consistent height and alignment.
- Left-side interactive menu button.
- Centered website branding and title.
- Right-side interactive menu button.
- Smooth transitions and visual feedback.
- Proper spacing on all screen sizes.

### 2. ◀️ Left Interactive Navigation

Add a button on the left side of the header.

When clicked:

- Open the left navigation panel.
- Display navigation links and useful shortcuts.
- Clicking again closes the panel.
- Clicking outside closes the panel.
- Pressing Escape closes the panel.

The panel must have a smooth opening and closing animation.

### 3. ▶️ Right Interactive Panel

Add a second interactive button on the right side of the header.

When clicked:

- Open a separate right-side panel.
- Display additional tools, information, or personal shortcuts.
- Clicking again closes the panel.
- Clicking outside closes the panel.
- Pressing Escape closes the panel.

Both panels must operate independently and never overlap incorrectly.

On smaller screens, use responsive drawers that fit the viewport.

### 4. 📦 Wrapped Main Content

The main content must use a centered, responsive wrapper.

Requirements:

- `width: 100%`.
- A controlled `max-width`.
- Automatic horizontal margins.
- Consistent internal padding.
- Proper spacing between sections.
- Independent vertical scrolling.
- Enough top and bottom space to prevent content from hiding behind the fixed header and footer.

The main container must remain visually centered on large screens while adapting naturally to tablets and mobile devices.

### 5. 🔻 Fixed Bottom Footer

Create a fixed footer attached to the bottom of the viewport.

Requirements:

- Always visible.
- Responsive height.
- Clean background and subtle separation from the content.
- Copyright information.
- Personal branding.
- Useful navigation or social links when appropriate.

The footer must never cover the last section of the main content.
